# TelegramFunnel Analytics

TelegramFunnel Analytics — веб-приложение для отслеживания и анализа воронки переходов в Telegram-каналы.

Система позволяет создавать трекинговые ссылки, собирать события кликов и подписок, рассчитывать конверсию, анализировать источники трафика и формировать PDF/Excel-отчёты с AI-аналитикой.

## Возможности

- создание и управление аналитическими проектами;
- генерация трекинговых ссылок с UTM-метками;
- отслеживание кликов и подписок в Telegram;
- расчёт конверсии воронки;
- анализ трафика по:
  - источникам;
  - кампаниям;
  - контенту;
  - датам;
  - географии;
  - устройствам и браузерам;
- интеграция с Telegram Bot API;
- асинхронная генерация отчётов через RabbitMQ;
- экспорт аналитики в PDF и Excel;
- отправка отчётов по email;
- AI-анализ статистики;
- хранение данных в PostgreSQL и MongoDB;
- фоновые задачи через Worker Service и Hangfire.

## Архитектура

```text
TelegramFunnelSolution
├── Projects
│   ├── TelegramAnalytic     # ASP.NET Core MVC веб-приложение
│   ├── ReportWorker         # фоновый worker для отчётов и AI-анализа
│   └── StatisticLibrary     # библиотека расчёта статистики
├── CommonMongoModels        # общие модели и контекст MongoDB
└── CommonRabbitMq           # сообщения и сервис для RabbitMQ
```

### TelegramAnalytic

Основное ASP.NET Core MVC-приложение.

Отвечает за:

- авторизацию пользователей;
- управление проектами;
- создание трекинговых ссылок;
- обработку кликов;
- интеграцию с Telegram-ботом;
- отслеживание подписок;
- отображение статистики;
- запуск генерации отчётов;
- запуск AI-анализа;
- взаимодействие с PostgreSQL, MongoDB и RabbitMQ.

### ReportWorker

Фоновый сервис для обработки тяжёлых задач.

Отвечает за:

- получение задач из RabbitMQ;
- расчёт статистики проекта;
- генерацию PDF-отчётов;
- генерацию Excel-отчётов;
- построение графиков;
- создание AI-аналитики по данным;
- отправку отчётов по email;
- обновление статусов отчётов в MongoDB.

### StatisticLibrary

Общая библиотека для расчёта аналитики.

Рассчитывает:

- общее количество кликов;
- количество подписок;
- уникальных пользователей;
- коэффициент конверсии;
- статистику по дням;
- статистику по UTM source;
- статистику по кампаниям;
- статистику по контенту;
- статистику по географии;
- статистику по устройствам и браузерам.

## Как работает система

Упрощённая логика воронки:

```text
Пользователь открывает трекинговую ссылку
                ↓
        Фиксируется клик
                ↓
   Пользователь переходит в Telegram
                ↓
       Фиксируется подписка
                ↓
   Клик и подписка сопоставляются
                ↓
      Рассчитывается статистика
                ↓
Dashboard / PDF / Excel / AI-анализ
```

Тяжёлые операции выполняются асинхронно:

```text
TelegramAnalytic
       ↓
    RabbitMQ
       ↓
  ReportWorker
       ↓
MongoDB / StatisticLibrary
       ↓
PDF / Excel / AI-анализ
       ↓
      Email
```


Статистику можно группировать по:

- UTM source;
- UTM campaign;
- UTM content;
- дням;
- географии;
- устройствам;
- браузерам.
